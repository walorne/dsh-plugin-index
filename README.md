# dsh-plugin-index

Персональный индекс плагинов для DeepSeek Harness (вкладка **Discover**).

## Добавить в Discover

Settings → Plugins → Discover → добавить индекс:

```
https://raw.githubusercontent.com/walorne/dsh-plugin-index/main/index.json
```

## Плагины

- [dsh-annotate-it](https://github.com/walorne/dsh-annotate-it) — разметка и ревью чатов и документов.
